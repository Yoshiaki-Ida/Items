# Items

開発効率化のためのプログラム集です。

## 収録プログラム

| プログラム | 用途 |
| --- | --- |
| [redmine-ticket-correction](redmine-ticket-correction/README.md) | 会議の取込JSONからRedmineの親子チケットを登録・確認する |
| [ManualTool](manual-tool/README.md) | Word・Markdown・HTMLを変換・編集し、複数のHTMLをマニュアルにまとめるWindowsツール |

## 利用方法

必要な環境、セットアップ、操作、テスト方法は各プログラムのREADMEを参照してください。

ManualToolの入手・起動手順は[配布フォルダのREADME](manual-tool/README.md)にあります。PlantUMLの図の編集・印刷や、指摘一覧のMarkdown出力は[操作ガイド](manual-tool/docs/USER_GUIDE_EMBEDDED.html)を参照してください。

会議の文字起こしから議事録を生成するSkillとAgentは、別リポジトリ
[shared-skills](https://github.com/Yoshiaki-Ida/shared-skills) で配布しています。
