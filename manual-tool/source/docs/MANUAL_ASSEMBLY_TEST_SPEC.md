# マニュアル統合・構築 テスト仕様

## 正常系

| 観点 | 確認内容 |
|---|---|
| 単一章 | 1章と目次を生成する |
| 複数章 | YAML順で結合・採番する |
| 章・節・項 | 3階層と個別HTML内見出しを連続採番する |
| HTMLと子要素 | `file`を持つ項目にも`children`を配置し、下位番号として出力する |
| 構成変更 | 並べ替え・途中追加・削除後に全番号を再計算する |
| 見出し変換 | 配置階層に応じてh1～h6を調整する |
| YAML往復 | 保存・再読込でSchemaが一致し、番号を保存しない |
| 目次 | 全見出しへのアンカーリンクを生成する |
| 採番対象外 | 本文と目次へ番号なしで掲載し、後続項目の採番へ影響しない |
| A4ページ | 完成HTMLをA4用紙単位で表示・印刷する |
| 章の改ページ | 最上位の章を必ず新しいA4ページから開始し、節・項は前へ詰める |
| 表の改ページ | 部品HTMLの外枠で一括改ページせず、表は見出し行を繰り返して行単位で前詰めする |
| 目次ページ | ドットリーダーと、描画後に確定したページ番号を表示する |
| アセット | ローカル画像をコピーし参照を書き換える |
| 再構築 | 前回生成後に参照されなくなったアセットだけを削除し、一覧外のファイルは保持する |
| 安定ID | `data-ref`を番号ではなくIDで解決する |
| 決定性 | 同じ入力から同じHTMLを生成する |
| GUI非依存 | CLIからYAMLを構築できる |
| API | フォルダ選択、YAML保存・読込、構築が連携する |

## 異常系

| 観点 | 確認内容 |
|---|---|
| 欠落HTML | YAML指定ファイルがない場合にエラー |
| 重複 | IDまたはHTMLの重複をエラー |
| 不正HTML | 非UTF-8、h1欠落、複数h1、見出し飛びをエラー |
| 不正階層 | 4階層をエラー |
| 欠落アセット | 画像・CSS等の参照先欠落をエラー |
| 出力先衝突 | `manual.output`と入力HTMLが同一の場合は構築を拒否し、原本を変更しない |
| 相対採番 | 個別HTML内の仮番号を除去し、構成から計算した本番番号へ置き換える |
| 不正YAML | Schema不一致・解析不能をエラー |

## 境界値・回帰

- 3階層は許可し4階層は拒否する。
- 空のマニュアルタイトル、空構成、空の項目タイトルを拒否する。
- プレビュー時も指摘ペインとドラッグリサイザーを維持する。
- フロントエンドが参照するDOM IDがすべて画面に存在する。

ファイルI/Oは`tmp_path`を使用し、Windowsのフォルダ・ファイル選択ダイアログはモックする。外部API、AI、クラウドサービスは呼び出さない。
